# Orbit mini-shop Release 0.5.28

## 本次目標

再降一層新手上手成本：用一鍵流程完成「跑通 demo → 核對是否可對外展示」的節奏，避免第一次用戶要在按鈕間切換心智模型。

## 主要變更

- 在 `docs/examples/mini-shop/apps/web/index.html` 的「第一次 demo（30 秒）」新增
  `一鍵 demo 檢核（成功→核對）`。
- 該按鈕行為：
  - 先執行一輪「成功」流程（與既有一鍵流程一致）
  - 緊接著回到「快速判斷值」區塊
  - 直接回報「服務/交易/關聯」是否三格皆綠
  - 用明確結果訊息說明是否可直接對外 demo

## 為什麼這能改善 UX

- 新手不再需要理解「先按哪個再看哪個」的順序：一個按鈕就完成最常見驗收動作。
- 保留了既有高階排錯能力（故障演練、故障卡、診斷命令）與 1.0 前的可驗證結構。
- 對於要做 release 前驗證、或第一次 demo 的使用者，能更快速降低 mental model。
