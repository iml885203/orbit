# Release 0.5.8（迷你店 UX 穩定性加值）

- 優化「下一步導引」的可執行性：錯誤快照與流程按鈕現在會直接對焦到可操作區塊
  - `cart_empty` 時，導向到「購物車」與「商品」區
  - `checkout` 失敗情境時，提供更明確的「一鍵成功流程」入口
  - 焦點導向更穩定：對非表單元素先加入可聚焦標記，避免點擊後沒對到目標位置
- 統一文案減少混淆
  - 將「8/8」明確標示為「後端服務 8/8」
  - 調整初始提示為「9 個資源（含 web）就緒」，對新手更直覺
- 補齊區塊錨點，讓快速操作的「聚焦」回傳到正確 UI 位置
  - 目標導覽、商品、購物車、checkout、訂單、庫存、出貨、關聯交易、時間軸、執行報告

本版改善目標：
- 幫助使用者在卡住時「不用猜」該按哪個按鈕
- 把操作心智負擔再降一階：從「先讀文字」變成「直接跳到可操作位置」。
