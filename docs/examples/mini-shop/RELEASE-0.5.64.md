# mini-shop Release 0.5.64

日期：2026-07-29

## 這版重點

- 進一步降低新手決策成本：
  - 「本輪 demo 一眼結論（30秒版）」改為只顯示 **1 個最優先下一步按鈕**，避免一次看到太多選項造成決策負擔。
  - 同步保留原有 `一輪 demo 結論` 的完整建議清單，確保進階需求下仍可看到全量資訊。

## 1.0 UX 對齊

本次調整針對「低 mental model」優化：

- 把「現在該做什麼」收斂為一個顯眼的主要動作；
- 減少新手在同時看到多個按鈕時的猶豫成本；
- 保留進階模式與既有操作鏈路，不改現有故障導向流程。

## 影響檔案

- `docs/examples/mini-shop/apps/web/index.html`
  - `setDemoVerdict()`：在 quick-demo 方卡中引入 `primary` 下一步建議。
