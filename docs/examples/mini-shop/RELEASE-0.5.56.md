# mini-shop 0.5.56

## 主要改善

- 為「故障演練」新增「回歸趨勢」一眼看版：
  - 顯示最近 3 輪回歸的通過率（例如 2/3 通過）。
  - 同步顯示最近 3 輪達標率（有在 120 秒回歸目標內）。
  - 根據結果自動以色彩（ok/warn/error）提示目前趨勢。
- 結合歷史卡片的空狀態與趨勢狀態，避免首次開啟頁面時不知道目前進度。

## 使用者體驗目的

- 減少新手在故障演練後的決策負擔：
  - 不只看到「最後一次」成功或失敗。
  - 先看到整體趨勢是否變好，才能快速決定要不要重跑演練。
- 強化「一次演練能否說明系統恢復性」的可觀測性，避免只靠單點結果做判斷。
