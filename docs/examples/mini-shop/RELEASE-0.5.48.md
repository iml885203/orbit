# mini-shop v0.5.48（1.0 打磨：再把「資料關係」做成一眼可讀）

## 為什麼這次
在 1.0 前階段，使用者可否快速判斷「本輪資料是否真的關聯」，是第一層體感。前幾版已經有服務就緒、交易、關聯三格，但仍然缺少「從資料面」的一眼對照。

本版把這層再往「可交付證據」補上一步：新增一個 `資料關係快覽` 區塊，讓使用者看到商品、客戶、購物車、訂單、出貨、關聯的關係，而不需要讀程式或打開多個 API。

## 這版做了什麼
- 在 `mini-shop` 前端加入「資料關係快覽」卡片，提供每輪可驗證指標：
  - 商品主檔數量
  - 客戶主檔數量
  - 低庫存預警（stock <= 5）
  - 選定客戶的購物車 items/小計
  - 交易總量與關聯結果（已關聯訂單數）
  - 本輪是否有可見證的關聯結果（最新訂單是否已對到出貨）
- 新增「`demo 指標 JSON`」可複製輸出，除了可視化文字快照，也保留可機器讀的交付證據，用於 release 對比。
- 將資料快照綁定到現有刷新鏈路：`loadCustomers`、`loadProducts`、`loadInventory`、`loadCart`、`refreshTransactionViews` 都會更新快覽輸出。
- 加入載入保護：當未選客戶時，購物車快照會重置，避免殘留上一位客戶資料造成誤導。

## 使用者體驗影響
- 第一次開啟 demo 時，除了服務三格，還會立即看到「這輪資料是怎麼串起來」的文字化關係圖。
- 在成功/失敗 demo 之後，能直接看到出貨是否真的有對應上訂單，不需先切進階診斷即可快速判斷。
- 對新手來說，整體認知路徑變成：
  1) 服務就緒 → 2) 成功流程 → 3) 關聯數據有無顯示。 

## 驗收
- `make preflight`
- 開啟 `mini-shop` 後確認資料關係快覽卡片：
  - 商品/客戶數會有數字
  - 選定客戶後會顯示 `購物車 items / 小計`
  - 完成成功流程後關聯結果能看到 `出貨` 和 `關聯` 的更新
- 重置流程後，快覽卡片會回到 `未選客戶` 與空資料狀態，不會帶入上輪殘留。
- 新增 `demo 指標 JSON` 複製出口：可直接貼到 PR/Release note 做一致性比對（例如是否可 demo、服務就緒、關聯耗時）。
