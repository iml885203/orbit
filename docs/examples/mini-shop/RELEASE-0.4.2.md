# mini-shop v0.4.2 (UX guidance polish)

## 目標

進一步降低首次使用者操作成本，讓使用者在遇到問題時可以不猜原因，直接得到「下一步該執行什麼」與「可複製診斷命令」。

## 完成項目

### 1) 一鍵可複製的診斷流程

- 在 web 頁面新增「診斷命令（可複製）」卡片。
- 根據目前流程狀態自動顯示建議指令，聚焦 `orbit status --json` 與對應 `logs`。
- 加入複製按鈕與回饋訊息，降低終端機切換摩擦。

### 2) 操作摘要（行為心智模型）

- 新增「操作摘要」欄位，顯示最近一次成功/失敗操作與原因。
- 在加入購物車、清空購物車、Checkout、刷新流程中同步更新摘要，讓結果可追蹤。

### 3) 文件對齊

- README 增加卡住時的排查建議，對應新 UI 的「診斷命令」功能。

## 對 1.0 前 UX 打磨的價值

- 降低新手卡關：除了顯示錯誤訊息，還提供下一步 CLI 指令。
- 減少上下文切換：UI 行為變成「可追蹤事件流」而非空白狀態。
- 開放式驗證：使用者可以直接對照 `orbit status --json` 與畫面建議。
