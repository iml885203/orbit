# mini-shop 0.5.51

## 主要改善

- 增加「超大主行動按鈕」：
  - `一次成功`：位在第一次 demo 區塊上方，專門讓第一次使用者在最短時間內完成一輪成功流程（清空→加入→checkout）。
  - `一鍵修復最近錯誤`：錯誤情境下顯示，提供可直接進行的修復入口，對應既有錯誤回復邏輯。
- 將超大修復按鈕與現有修復機制綁定，與右側「現在只要做一件事」保持一致行為。
- 同步補齊 disable 邏輯，避免流程中斷時誤點。
- 在 mini-shop README 補上「60 秒最短成功路徑」的可執行文案，降低首次上手心智模型。

## 驗證結果

- 行為上：點擊「一次成功」可以直接觸發一鍵成功路徑並回到結果面板。
- 行為上：有可見錯誤碼時，超大修復按鈕會顯示啟用並可執行一鍵修復。
- 文件上：新增 `README` 60 秒最短路徑說明，讓新手可先依快速路徑判斷是否可 demo。

## 使用者體驗目的

- 用超大按鈕做首次路徑決定，讓「我現在該做什麼」變成唯一可見明確行為。
- 不改變原本進階能力，僅降低第一次上手選擇成本。
