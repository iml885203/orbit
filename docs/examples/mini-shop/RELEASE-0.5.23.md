# Orbit Mini-Shop (0.5.23) — 1.0 前最後 UX 抽象化打磨

## 目標

讓「下一步怎麼做」直接對應到可執行命令，讓新手不必先理解所有卡片結構。

## 核心改善（本版新增）

- 「現在只要做一件事」面板新增 copy 行為：
  - 對有可執行命令的建議，會同時顯示「複製下一步命令」。
  - 支援一鍵複製，操作完成後有短暫回饋訊息。
- 第 1 步（服務就緒）更新為指令主導：
  - 下一步從「重新整理」轉成可直接複製 `orbit -c docs/examples/mini-shop/dev.yaml status --json`。
  - 讓使用者先有一個明確、可靠的狀態來源。
- 錯誤/修復建議也會同步補齊可複製命令（保留既有焦點/重試動線）：
  - 當單步建議是 copy 類型時，單行面板會同步顯示對應命令。
- 故障演練也新增可複製腳本：`down cart-api -> status -> restart cart-api -> status`，讓卡住後能以最小認知操作恢復 demo。

## 使用者心理模型降低的觀察

- 使用者只要對著同一個區塊閱讀：「接下來做什麼 + 要複製什麼命令」，不必再在頁面不同區塊搜尋。
- 從「想幫我做下一步」到「我能直接貼 terminal」的步驟減少到 1 步。

## 驗證

- 開啟 mini-shop 首頁，未就緒時：
  - 「現在只要做一件事」會顯示第 1 步建議，並可複製 status 命令。
- 人工驗證失敗修復流程時：
  - 故障卡主建議為 copy 類型時，該按鈕也會出現在單一步驟區並可複製。
