# mini-shop 0.5.53

## 主要改善

- 新增「首次可 demo 耗時」可視化與量化指標：
  - 在「執行報告」加入 `首次可 demo 耗時`，回報成功完成一次關聯交易前後用了多久。
  - 在「目前進度」新增「60 秒目標」與「實際可用時間」：
    - 目標達成/未達標一目了然
    - 顯示從啟動到可 demo 的實際耗時
- 將 demo 指標同步到可匯出 JSON，作為 smoke script / CI 可讀的驗收輸出。
- 持續保留既有成功/失敗情境與操作節奏，確保可在新手預期時間內完成「一次成功 + 一次回歸」。

## 使用者體驗目的

- 讓第一輪使用者不只知道「能不能 demo」，還能知道「多快能進入可 demo 狀態」，降低啟動時的心理負擔。
- 以明確可量化訊號取代猜測，讓新手容易判斷是否該繼續點操作、還是應該先重啟某個 service。
- 將使用者感知的品質（速度、可預期性）變成可看見的指標，支持你在 1.0 前做可量測打磨。

## 驗收結果

- 執行 mini-shop 頁面流程後，「執行報告」會顯示：
  - `首次可 demo 耗時`
  - 成功且關聯完成時，會附上是否在 60 秒目標內。
- 「目前進度」會顯示：
  - `60 秒目標`（達標/未達標）
  - `實際可用時間`
- 透過頁面內建 export 指令，可在每次變更後拿到 `demo_within_60s`、`first_demo_elapsed_ms`、`boot_to_demo_elapsed_ms` 等欄位做回歸比較。
