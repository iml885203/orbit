# mini-shop v0.4.6（流程完成度與重置路徑）

## 目標
讓第一次使用者不只知道下一步要做什麼，而是可以「可預期地重複成功」。

## 本次完成項目

### 1) 流程完成度卡片

- 在 `下一步（照著做）` 區塊新增 `流程完成度` 列表。
- 透過四步完成度（服務就緒 → 選客戶 → 進入購物車 → Checkout 成交）呈現進度：
  - ✅ 已完成
  - 👉 當前步驟
  - ◯ 未到步驟
- 當狀態變化時即時更新，讓使用者更容易知道現在該做哪件事。

### 2) 重置流程按鈕

- 新增 `重置流程`：
  - 選回預設客戶與商品
  - 數量重設為 1
  - 付款方式重設為 `mock_card`
  - 清空目前客戶購物車
  - 重新刷新頁面資料
- 目的是支援「演示中斷」後快速回到可重跑起點。

### 3) 文件補充

- README 增補：
  - 明確提醒在卡住時優先看「下一步/進度卡」
  - 補上重置流程的使用方式，降低反覆操作成本
  - 增加 demo 重複性建議

## 對 1.0 打磨價值

- 降低「操作要不要重來」的認知負擔。
- 讓使用者更容易維持對正確路徑的信心。
- 即使出錯，也能快速回到起點，持續進行 onboarding。
