# mini-shop v0.5.50（1.0 打磨：加速第一輪認知）

## 為什麼這次
第一輪 demo 的關鍵不是功能更多，而是「看完頁面就知道我現在在哪步」。  
本版補上目標導覽的進度視覺化，讓使用者不用先讀完 5 條文字就能判斷下一步。

## 這版做了什麼
- 新增「一頁式目標導覽」上方進度條與進度標籤（`進度：n / 5（%）`）。
- 進度條會根據系統推論的目標步驟即時更新，並在關聯完成後變成完成色，讓「可 demo」狀態一眼看出。
- 維持既有「現在只要做一件事」邏輯，但提供更明確視覺引導。

## 使用者體驗影響
- 進入 demo 後，使用者第一眼可看到當前進度，對「該做什麼」的腦內切換更快。
- 導覽邏輯不變，僅增加可視化提示，降低閱讀負擔與誤操作機率。

## 驗收
- `make preflight`
- 開啟 `mini-shop` 首頁，確認「一頁式目標導覽」顯示進度條。
- 在服務未就緒、已加入商品、checkout 後逐步操作，觀察進度百分比與步驟數是否連動。
- 完成訂單與出貨關聯後，進度條需顯示接近完成狀態並提升為完成色（可理解為已可 demo）。
