# mini-shop v0.4.1 (UX polish before 1.0)

## 目標

讓 `mini-shop` 不只是「能跑」，而是「第一次打開也能知道該做什麼」，並且在出錯時知道下一步該做什麼。這是對 1.0 前最重要的心理模型打磨之一。

## 完成項目

### 1) 互動流程導引（前端）

- 新增「快速導覽」與「服務關係」區塊，幫助首次使用者先建立流程預期。
- 將狀態訊息從「是否可 checkout」升級為「服務就緒度 + 失敗候選節點」。
- 將主要按鈕的啟用條件與服務可用性綁定，避免用戶在不可用時誤操作。

### 2) 錯誤回饋可行動化

- 將 API 錯誤轉換為可讀文案，例如：
  - 庫存不足
  - 購物車為空
  - 服務未就緒
  - 付款失敗
- 同步更新提示為「採取哪個下一步」，降低猜測成本。

### 3) 心智模型降噪

- 在頁面新增「你看得懂的依賴圖」文字版，將複雜 service call chain 視覺化為 checkout 中心流程。
- 強化 README 的新手驗收流程與操作順序說明。

### 4) 小幅清理

- 移除 `payment-api` 未使用 import，降低 lint/noise。

## 針對 1.0 前評估的價值

- 使用者不需閱讀原始碼就能理解目前可做什麼。
- 啟動/故障定位時不需要大量猜測，第一時間可對齊 `orbit status --json` 與頁面提示。
- 可逐步新增「故障注入場景」與新 feature，不會破壞目前體驗主線。
