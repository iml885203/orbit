# mini-shop v0.5.43（1.0 打磨：結論卡引導行動）

## 打磨目標

讓使用者在看到「尚未可 demo」時，不只知道缺口在哪，而是能立刻接著做下一步，避免再次「看了但不知道按哪個」的思考停頓。

## 這版變更

- `docs/examples/mini-shop/apps/web/index.html`
  - 「一輪 demo 結論（先看這裡）」卡片新增行動按鈕區：
    - 不可 demo 時直接跳轉到對應區塊（服務、流程、關聯）；
    - 可 demo 時提供「複製 demo 報告」按鈕。
  - 點擊行動按鈕會直接執行既有導向邏輯（聚焦目標區塊）或複製可複製報告。

- `docs/examples/mini-shop/README.md`
  - 補上「結論卡可直接導向下一步」的驗證說明，讓新使用者知道看到缺口後該怎麼做。

- `docs/examples/mini-shop/UX-SMOKE-CHECK.md`
  - 在 30 秒 smoke 檢核中明確要求核對「結論卡 + 導向建議」。

## 打磨效果（對應 1.0 心智模型）

- 心智負擔再降一階：可直接讀取「可 demo 狀態」與「下一步行動」。
- 錯誤修復鏈更完整：從「發現問題」直接到「修復入口」。
- release 可見度更高：每次版本改動都能被一眼判斷為「改善了什麼決策點」。
