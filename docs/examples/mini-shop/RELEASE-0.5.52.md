# mini-shop 0.5.52

## 主要改善

- 新增「新手 / 進階」顯示策略的進一步壓縮：
  - 新手模式會自動隱藏更多高階資訊卡（觀測、關聯地圖、故障演練、診斷命令、操作回應、快速導覽、情境加速面板等），保留主流程與「能否 demo」的最少訊號。
  - 進階模式保留同樣主流程，並同時展開完整診斷與除錯訊息。
- 在模式切換區新增明確提示，讓使用者知道新手模式是「先只保留能完成任務的最少欄位」。
- 將高階卡片隱藏邏輯從 DOM 層集中到 `compact-mode-hide` 標記，降低未來維運成本（新增/調整卡片時可靠 class 做一致策略）。
- 更新 mini-shop README，將「下一步（照著做）」說明改為進階模式可見，避免文件與實際顯示不一致。

## 使用者體驗目的

- 進一步降低第一次上手的認知負擔：減少「資訊噪音」，讓第一輪只聚焦服務就緒、加入購物車、checkout、關聯結果。
- 以保留與收斂並行進行：進階場景不丟掉排障能力，只在新手模式下延後曝光。

## 驗收結果

- 行為上：切到新手模式時，標記為 `compact-mode-hide` 的卡片會被隱藏；切回進階會恢復。\n+- 行為上：`advanced-only` 的區塊維持原本進階邏輯，並與「新手/進階」共用一致收斂節奏。
- 文件上：README 的一次性驗收流程已同步新行為。
