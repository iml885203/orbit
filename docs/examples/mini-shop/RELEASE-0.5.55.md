# mini-shop 0.5.55

## 主要改善

- 新增「故障演練歷史」卡片，保留最近 5 次回歸結果，讓使用者能一眼比較趨勢。
  - 每筆紀錄顯示：PASS/FAIL、回歸耗時、是否達標、與最近一次失敗的時間距離。
  - 當尚未有紀錄時，保留清楚的預設提示，避免空白視覺。
- 首次載入頁面會立即初始化故障演練歷史區，避免首次到達時不知道目前狀態。
- 確保「故障演練」每次回歸（含未建立 baseline 的情況）都會追加摘要紀錄，強化可追溯性。

## 使用者體驗目的

- 讓新手在同一頁面完成：
  - 失敗後，先知道目前失敗點（已存在的定位卡）。
  - 回復後，先知道這輪是否達標。 
  - 多輪後，能直接觀察趨勢是否改善。
- 降低「要不要重試」的猜測成本，讓 demo/回歸變得更像 checklist，而非自由摸索。
