# Release 0.5.10（目標導覽與錯誤回饋減少心智負擔）

## 重點

- 把「下一步應該看哪裡」轉成視覺導引：
  - 根據目前流程步驟（服務就緒→客戶→購物車→Checkout→結果）自動高亮相關卡片。
  - 保留原本進度敘事，但多一層「現在我該看哪裡」的指示。
- 錯誤時同步高亮相關區塊：
  - 從故障代碼直接對應商品/購物車/庫存/結帳/訂單等卡片。
  - 讓新手不用先猜是哪個畫面才是根因。
- `目標導覽` 操作時也會同步帶出對應卡片 focus。
- 提升可理解性與無障礙性：
  - 高亮卡片有短時間脈衝動畫與邊框。
  - 開啟 `prefers-reduced-motion` 時自動關閉動畫，保留高對比提示。
- `scrollToAndFocus` 也會輔助標記已導覽目標，避免長頁面時找不到重點。

## 使用者觀感改善

- 測試同一流程時，使用者可直接追著高亮卡片走完「服務就緒 → Checkout → 關聯結果」。
- 失敗時的導向更直接，從錯誤代碼到「去看哪個區域」的轉換變短。
- 整體認知步驟由「一次看很多資訊」改為「只看一個當前目標區」。
