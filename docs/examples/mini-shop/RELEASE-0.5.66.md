# mini-shop 0.5.66

## 本次目標

進一步落實「第一次開啟即能上手」：把新手模式的行動按鈕縮到最少，降低選擇負擔。

## 打磨內容

### 新手模式隱藏高噪音操作

- 在 `第一次 demo（30 秒）` 中，新增 `beginner-mode-hide` 控制層，當模式為「新手」時自動隱藏高階操作按鈕：
  - 一鍵 demo 檢核
  - demo 報告 / 指標複製
  - 進階啟動指令
  - smoke / onboarding 腳本複製
  - 故障演練相關複製項目
- 保留新手首要操作：
  - `開始 demo 一輪`
  - `核對可 demo 條件`
  - `先看核對清單`
- 進階模式不受影響，仍保留完整命令複製能力。

## 使用者體驗影響

- 首次看到頁面時，不必在大量命令按鈕裡決定先按哪個。
- 新手行為路徑維持「按鈕最少、結果最直接」：先把流程跑通，再逐步進階。
- 對「mental model」目標的影響：
  - 減少認知分心
  - 更容易理解「目前唯一正確路徑」
  - 仍可在進階模式回到全量工具
