# mini-shop 0.5.74

## 1.0 前 UX 打磨：新手流程再壓縮（降低首屏心智負擔）

- 在新手模式中，將首頁 quick-start 操作縮減到核心路徑：
  - 顯示「一鍵完成第一輪 demo（約 1 分鐘）」與「核對可 demo 條件」
  - 隱藏較進階的重播/檢核/指令複製入口（這些改在進階模式可用）
- 同步精簡導覽文字，明確告訴新手只需兩步即可拿到可 demo 結論。

### 對使用者體驗的直接影響

- 新手一開畫面可直接聚焦「能否 demo」的最小路徑，減少在大量按鈕中的判斷停頓。
- 進階流程保留完整，不影響排障與深度診斷能力，避免為簡化新手體驗犧牲可觀測能力。
