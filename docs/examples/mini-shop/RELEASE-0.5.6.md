# Release 0.5.6 (mini-shop UX polish)

- 新增「操作回應快照」區塊（mini-shop 主要流程）
  - 追蹤手動 checkout、加/清空購物車、情境重放等關鍵操作
  - 顯示每次 call 的 service、action、HTTP、耗時與結果
  - 自動保留最近 12 筆，讓新手能快速知道目前卡在哪一段
- 將關鍵 API 呼叫統一走可追蹤 wrapper
  - 觀察層面更一致，不再只靠操作摘要間接猜測錯誤位置
  - 背景輪詢不會干擾 log，避免噪音
- 優化錯誤回饋可視化
  - 操作失敗時快照會保留 code 與下一步提示，搭配「故障情境對照卡」快速導引排查
- 目標導覽 / 一鍵流程可用於驗證
  - 新手在不知道 service 細節前，仍可透過快照看見成功/失敗是否來自 cart、payment、inventory 或 checkout

本版改善目標：
- 降低第一支線上 demo 的心智成本
- 提供「可觀測」而非「可猜測」的操作體驗
- 讓 release 之間有明確可展示差異
