# mini-shop v0.5.1（導覽導向打磨：一鍵引導到可完成流程）

目標是讓新手不用看說明文件，就能直接完成一筆成功的 mini-shop 流程，並看懂服務怎麼串。

## 這版重點

- 新增「一頁式目標導覽」：
  - 5 步流程（服務就緒 → 選客戶 → 加入購物車 → Checkout → 核對結果）
  - 自動標示目前步驟 / 已完成步驟
  - 目標導覽區顯示下一步要做什麼
- 目標導覽新增「下一步操作建議」按鈕：
  - 可自動幫你完成對應步驟：
    - 等服務就緒時先 `refresh`
    - 自動選客戶
    - 自動加入一筆商品
    - 以 `mock_card` 幫你走一次 checkout
    - 流程完成後導向結果區
- 新增「重做一次成功流程」：
  - 快速回到可重複演示的起始狀態（清空購物車＋預設付款方式）

## 期待 UX 影響

- 心智負擔降低：不需要同時記住服務、按鈕、驗證順序。
- 降低停滯：卡在某步可直接按按鈕前進，不會「我該做什麼」不清楚。
- 成果可見：頁面上同時有流程卡、執行報告、關聯時間軸，成功與否立即可驗證。

## 驗收建議

1. 啟動 demo 後，確認「一頁式目標導覽」先看到步驟 1。
2. 點「下一步操作建議」反覆前進，觀察它是否會讓流程自然進到下一步。
3. 看到「已到達目標」後，點「重做一次成功流程」回到起始，重複一次。
4. 在過程中失敗時，確認「執行報告」與「故障情境對照卡」同步更新。
