# mini-shop v0.5.0（故障情境對照卡 + 固定可用操作引導）

這一版目標是降低新手在錯誤時的心智負擔：

- 新增「故障情境對照卡」常駐於前端，不用再自己對照文件。
- 錯誤發生時，自動高亮最相關錯誤代碼，並顯示「下一步建議」與可複製命令。
- 每條對照項目都能直接複製命令，從「看到錯誤」到「開始排障」的步驟縮短為 1 步。

## 新增 UX 變更

1. 頁面常駐卡片
   - 新增 `故障情境對照卡（先照表走）`
   - 每個卡片顯示：錯誤代碼 / 症狀 / 建議動作 / 快速命令

2. 錯誤反饋一致化
   - 發生錯誤時會同時更新執行報告與故障對照卡高亮，降低「錯誤後不知道下一步」的摩擦。
   - 刷新 / 重置等流程失敗時也會顯示對應的對照資訊。

3. 記憶負擔下降
   - 將「需要看哪個 service log」綁在同一個卡片，不必先切到診斷命令再逐一猜測。
   - 成功流程維持原本時間軸 + 操作摘要行為，讓新手能專注在交易是否完成。

## 如何驗收

1. 一定會看到對照卡在頁面中。
2. 人為讓 checkout 失敗（如付款失敗），確認對照卡自動高亮 `payment_declined`。
3. 點對照卡中的「複製命令」後，貼上終端可直接進行 logs / status 驗證。
