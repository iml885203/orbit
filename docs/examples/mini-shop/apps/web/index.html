第一次啟動檢查（最少心智負擔）

  1. 先確認有 5 個 resource 在跑：redis / catalog-api / inventory-api / order-api / web
  2. 等 order-api 顯示 status=ok 後再開分頁
  3. 用「下單」下 1 個產品、1 件數量，若成功會同時更新訂單與庫存

若下單失敗，先看錯誤訊息：通常是 insufficient_stock（庫存不足）或 某服務未啟動（先確認 orbit status --json）。
