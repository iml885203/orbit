Orbit mini-shop

目標很簡單：選客戶 → 加入購物車 → Checkout。你不用先記 API，也不用先猜 service 邏輯。

這個 demo 想證明 3 件事：主機與容器混合、跨 service 的資料關聯、以及發生問題時可以快速定位。

    服務關係（你可不用記）

    從資料流向來看：
    web
  └─ checkout-api
       ├─ cart-api → catalog-api
       ├─ order-api → catalog-api / inventory-api / customer-api
       ├─ inventory-api
       ├─ payment-api
       └─ shipping-api

    也就是你只要追一個主流程節點 checkout-api 即可理解全域。
