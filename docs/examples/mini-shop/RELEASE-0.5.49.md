# mini-shop v0.5.49（1.0 打磨：降低第一印象摩擦）

## 為什麼這次
在 1.0 前，我們要持續收斂「第一次看到頁面時的心理負擔」：
- 快速操作入口要整齊清楚，先別讓排版先失焦；
- 可交付輸出要能在沒有額外閱讀的情況下直接複製使用。

本版聚焦這兩件事，先收斂微小但直接影響體感的細節。

## 這版做了什麼
- 修正 `第一次 demo（30 秒）` 按鈕排版縮排，避免新手誤以為是排版錯亂，保證快速啟動區塊外觀一致。
- 加入 `demo 指標 JSON` 複製條件的防呆：當尚未有任何服務/交易線索時不會直接輸出空 JSON，減少「按了沒用」體驗。
- README 的快速操作清單序號修正，維持新手導引文本一致性。

## 使用者體驗影響
- 30 秒區塊看起來更穩定，按鈕間距一致，降低第一眼雜訊。
- `複製 demo 指標 JSON` 在有效時才啟動，會回報更具意義的輸出，避免無效複製。
- 交付對照文案更一致，方便 PR/review 直接對照版本差異。

## 驗收
- `make preflight`
- 開啟 mini-shop 首頁，確認第一次 demo 的四個快速按鈕與兩組情境按鈕排列整齊、可點。
- 尚未執行成功流程時，按「複製 demo 指標 JSON」會提示先完成流程；成功後會複製可貼 PR 的 JSON。
- README「首次最小心智體驗」步驟序號連續且正確。
