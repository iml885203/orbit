# mini-shop 0.5.67

## 本次目標

再進一步降低第一次使用者的決策步驟：將「先跑流程」和「核對可 demo」變成一鍵行為。

## UX 打磨

### 新增 `新手一鍵完成第一輪 demo` CTA

- 在 `第一次 demo（30 秒）` 區段新增按鈕：`一鍵完成第一輪 demo（約 1 分鐘）`。
- 行為流程：
  1. 直接執行「一輪成功流程」
  2. 立刻核對「服務 / 交易 / 關聯」三格可否 demo
  3. 依結果回報：
     - 成功：`可直接對外 demo`
     - 部分成功：自動引導到 `1.0 交付前檢核清單`
     - 失敗：提示先確認服務就緒

- 一致性處理：與現有按鈕狀態一致，執行期間會與其他互動按鈕一起停用，避免同時操作衝突。

## 這輪對 1.0 使用者體驗的影響

- 新手可以不需要自己組合兩個按鈕（先 run 再核對）。
- 縮短「想到要按哪裡」的認知時間。
- 讓首次目標更清楚：在最短時間拿到「可對外 demo」或「下一步應修」。
