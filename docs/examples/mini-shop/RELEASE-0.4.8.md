# mini-shop v0.4.8（交易時間軸與失敗可視化）

讓 `mini-shop` 從「有東西可點」變成「每次 checkout 的結果可追溯」。

## 你現在會看到的差異

- 加入「關聯流程時間軸」卡片，將每次 checkout 的關鍵節點（開始/庫存保留/付款/建立訂單/建立出貨）視覺化。
- 時間軸會同步顯示成功與失敗，付款失敗可直接看到 `code`，避免只看到一個紅字。
- 當你下單、清空、切換流程、重複整理時，
  「最近關聯交易」「關聯流程時間軸」「執行報告」會一起刷新，
  一次能對齊：
  - 最終結果（訂單）
  - 失敗原因（回傳 code）
  - 下一步建議（診斷命令）
- 重置與清空會清掉上一筆 checkout 的快照，避免重複解讀上一輪結果。

## 用法提醒（心智模型減負）

1. 完成選擇客戶與加入購物車。
2. 按下 Checkout。
3. 在「關聯流程時間軸」直接看到 checkout 流程是否到齊「付款成功 / 建立出貨」。
4. 若失敗，在執行報告與時間軸看到同一個「失敗原因」。
