# mini-shop v0.4.9（診斷友善：時間軸可直接複製日誌命令）

目標不是做更多邏輯，而是讓新手能「更快定位問題」。

## UX 改善

- 在「關聯流程時間軸」每個階段都提供對應 service log 命令（卡片內直接可複製），降低需要切換到「診斷命令」區才能定位的摩擦。
- 失敗結果不只顯示錯誤文案，會補上可執行建議（例如：改 mock_card、先檢查庫存/服務是否 ready）。
- 錯誤報告會把「要看哪個 service 日誌」放在同一個上下文，不必猜下一步。

## 適合展示的情境

1. 情境 B（付款失敗）
   - Checkout 會在時間軸顯示付款失敗步驟。
   - 可直接複製 `payment-api` 的 log 指令。
2. 情境 C（庫存不足）
   - 失敗文案會提示縮小數量、檢查庫存服務。
