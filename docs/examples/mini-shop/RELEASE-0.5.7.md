# Release 0.5.7 (mini-shop UX actionable recovery)

- 將「操作回應快照」變成可執行導引，而不是只讀記錄
  - 每筆錯誤快照會提供可點按建議：
    - 複製診斷命令
    - 複製對應 service log 命令
    - 一鍵切 `mock_card` 重試（付款失敗情境）
    - 直接跳到下一步導覽區塊
- 增加 action 按鈕互動，不再只靠文字提示
  - 點完可立刻對齊到關鍵區域（購物車、商品、目標導覽）
  - 避免新手在 CLI 命令與畫面之間來回切換
- 新增「快照重試」邏輯
  - 在快照上直接重試 checkout，保留操作摘要與最新回報，讓新手可在同一個位置完成修復

本版改善目標：
- 把 demo 的 UX 從「看得到發生了什麼」升級為「知道接下來該做什麼」，
- 降低新手的操作切換成本，持續提升首次開箱完成率。
