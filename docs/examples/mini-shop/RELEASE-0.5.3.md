# mini-shop v0.5.3（加速驗證：結果一眼可見 + 情境耗時預期）

這版把「我要怎麼驗證成功」的資訊前移，避免使用者停在畫面上不清楚接下來是否真的完成。

## 變更重點

- 新增「當前可驗證結果」卡片
  - 直接展示：最新訂單、對應出貨、最近 checkout 結果（含時間）
  - 每次交易視圖刷新時自動更新
  - 讓使用者不用在「訂單/出貨/時間軸」多卡片間來回查詢
- 一鍵情境新增「預估時間」提示
  - 成功/付款失敗情境：通常 < 5 秒
  - 庫存不足情境：通常 < 8 秒

## 為什麼更好

- 減少認知成本：用戶能立刻確認「是否可驗證到目標結果」。
- 減少等待焦慮：看到估時後知道何時該切換到診斷。
- demo 演示更穩定：即便第一次使用，也能快速完成一次完整關係驗證。

## 驗收建議

1. 啟動後點情境，觀察「當前可驗證結果」是否更新。
2. 成功 checkout 應看到：
   - 訂單區出現最新訂單（含客戶、商品、狀態）
   - 出貨區出現對應出貨
   - Checkout 結果列顯示最近一次結果
3. 若情境卡片提示仍無結果超時，先依「診斷命令」走排障流程。
