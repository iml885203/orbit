# Release 0.5.11（故障導引可操作化，減少錯誤時心智負擔）

## 重點

- 將故障情境卡改成可直接操作的導覽：
  - 每個錯誤碼卡新增「定位到對應區塊」按鈕。
  - 點擊後自動捲到重點卡片並顯示對應 focus，避免新手先找半天頁面。
- 「複製命令」保留在卡片中，維持「快速下一步」與「快速診斷」雙軌行為。
- 目標導向提示與錯誤導向統一：
  - 錯誤時會同時高亮相關卡片。
  - 操作完成後會留下簡短「已定位到目標」摘要。

## 使用者觀感改善

- 失敗時只要看到卡片就能直接完成下一步：
  1) 一鍵定位到對應區塊。
  2) 針對該區塊再按「下一步建議」或複製診斷命令。
- 進一步縮短「知道出錯了」到「知道要做什麼」的時間。
