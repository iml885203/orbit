# mini-shop 0.5.57

## 主要改善

- 在「故障演練」新增「下一步行動」提示卡（`#drill-next-hint`）：
  - 無紀錄時引導建立基線。
  - 有紀錄且未達標時引導：先修復失敗後再回到 `3 秒可 demo 指標`。
  - 通過但未達目標時提醒再重跑一次演練。
  - 通過且達標時提示可複製回歸報告與做下一輪確認。
- 將提示與「故障演練歷史 / 趨勢」綁定更新，避免使用者要靠經驗猜下一步。

## 使用者體驗目的

- 讓故障演練從「看結果」變成「看下一步可做什麼」，降低操作猶豫。
- 讓 demo 失敗者也知道下一秒該做的事，而不是回到空白頁面自行猜。
