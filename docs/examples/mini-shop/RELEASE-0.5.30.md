# Orbit mini-shop Release 0.5.30

## 本次目標

進一步降低新手認知負擔：加上「營運快覽」面板，讓使用者不需要先追每張明細，就能先知道 demo 是否具備可交付條件。

## 主要變更

- `docs/examples/mini-shop/apps/web/index.html`
  - 新增「營運快覽（無需進入技術細節）」卡片與指標：
    - 服務就緒（`ok / total`）
    - 本輪成功訂單 / 失敗 / 待處理
    - 已關聯出貨筆數
    - 最近交易是否「服務 + 交易 + 關聯」可 demo
  - 所有交易視覺更新會在 `訂單/出貨` 更新後同步重算，維持一個「商業化」角度的一頁式理解。
- `docs/examples/mini-shop/README.md`
  - 補上營運快覽可快速判斷交付的使用說明。

## 使用者價值

- 使用者第一次看到結果時，不用先理解每個 service log，就能先看到「是成功、是否關聯、下一步做什麼」。
- 保持一鍵 demo、情境重播、故障演練既有流程不變，只是把「最後是否可交付」先前隱藏的判斷聚合成可視化卡片。

## 驗收建議

- 新手流程：開啟 demo → 按一次「開始 demo 一輪」→ 看營運快覽是否顯示「可 demo：Yes」與關聯/出貨資訊。
