# mini-shop 0.5.65

## 本次目標

讓第一次打開 mini-shop 的新手體驗更短、更集中，減少同時處理的資訊量，讓「我現在該做什麼」更容易一眼判斷。

## UX 打磨

### 新增：新手模式預設隱藏情境故事卡

- 將 `情境導演（先做這 3 個）` 卡片改為 `compact-mode-hide`。
- 這代表它在新手模式預設隱藏，保留給進階模式使用。
- 對應效果：新手第一次看到的 UI 更短，先聚焦在
  - `首次 demo（30 秒）`
  - `本輪 demo 一眼結論`
  - `一眼看懂進度`（視野內的關鍵信號）
- 仍保留 `進階模式` 全量操作與情境測試，避免首次上手時被一次性大量指令與情境選項干擾。

## 預期使用者心理模型收益

- 導覽決策從「看很多卡片選要不要做哪個」降為「先做 30 秒主線，再進階」。
- 新手在 `新手模式` 能更快完成第一輪成功/可 demo，減少啟動時的認知負擔。
- 不需要新增任何 service 或流程，只是降低第一輪視覺複雜度。
