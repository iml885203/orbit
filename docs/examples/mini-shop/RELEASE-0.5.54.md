# mini-shop 0.5.54

## 主要改善

- 為「故障演練」補上回歸可量化指標：
  - 新增故障回歸報告中的「失敗回歸目標 / 回歸耗時」欄位，支援 120 秒回歸門檻可視化。
  - 新增 `複製故障演練指標 JSON`，同時輸出：
    - `baseline_elapsed_ms`
    - `verify_elapsed_ms`
    - `verify_within_target`
    - `last_failure_code`
    - `last_failure_age_ms`
- 失敗發生時記錄時間戳，讓回歸判斷除了三格訊號外，還有「是最近故障後多久復原成功」的參考。
- 保留既有「故障演練回歸報告」與快速恢復步驟，強化可追蹤，不改變原有 flow。

## 使用者體驗目的

- 將「故障後是否可快速回到可 demo」從主觀感覺變成可讀數據，降低判斷負擔。
- 讓 reviewer 在每次打磨中可以快速看到新版本是否真的改善了回歸韌性，而非只看畫面文案。

## 驗收結果

- 故障演練報告會直接顯示回歸目標達標與耗時判讀。
- 成功 prime + verify 後可直接複製「故障演練指標 JSON」，作為回歸與 CI 的可讀輸出。
