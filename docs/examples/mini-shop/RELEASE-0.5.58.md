# mini-shop 0.5.58

## 主要改善

- 將「故障演練（1/2 分鐘）」的下一步從純文字提示，改成可執行的一步式行為導向：
  - 建立基線（先做一輪成功流程）
  - 自動補上最近故障修復
  - 回歸驗證並自動記錄指標
  - 通過後可直接複製故障回歸報告
- 導入「故障演練下一步建議」的動態文案與 button 狀態同步更新，避免使用者在不同結果間反覆猜下一步。
- 發布與驗收文件補齊：把 mini-shop 近期 release 參考更新為最新版本，讓你每次發版都能快速回看差異。

## 1.0 UX 打磨目的對齊（本次驗證）

- 新手在故障情境下，不需要先看 console；只需看頁面卡片與 CTA 即可知道下一步。
- 失敗、超時、通過三種狀態都會引導到不同操作，不是回到同一個 static 提示。
- 修復與驗證在同一頁面完成，降低對「多頁文件 + 記憶命令」的依賴。

## 交付前最小驗收（建議）

- [ ] 啟動後在新手模式能在 2 分鐘內看到「故障演練」的可執行下一步。
- [ ] 失敗後可直接啟動「一鍵修復最近錯誤」或等價快速建議。
- [ ] 「回到 3 秒可 demo 指標」能更新 `快速判斷值` 並在回歸歷程留下紀錄。
- [ ] 至少可產出一版「故障回歸報告」作為 release 可追蹤輸出。
- [ ] `make preflight` 通過。

## 本次差異重點（對比 0.5.57）

- 前次以「文字提示」為主，本次新增「行為化」下一步；主要提升點在於降低用戶在故障情境的 mental model，不需要再猜。
