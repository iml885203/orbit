# mini-shop v0.5.2（進度一覽卡：降低認知負擔）

這版繼續把 demo 做成「看一眼就知道做了什麼、差什麼」的體驗，避免新手在多卡片裡迷路。

## 變更重點

- 新增「一眼看懂進度」卡片（4 格檢核）
  - 服務就緒
  - 是否已選客戶
  - 是否已加入購物車
  - 是否完成成功 checkout
- 進度卡會隨 `checkAll` 自動更新，與「一頁式目標導覽」同步。
- 即使使用者跳過步驟、或執行情境/重試後，卡片仍保留最新狀態，降低猜測成本。

## 為什麼有價值

- 讓第一次操作者更快建立 mental model：
  「我現在應該先做哪一項」直接可視。
- 減少在不同區塊間來回找資訊的認知切換。
- 有助於 demo 演示時快速判斷：是否已到可 checkout、是否已完成成功結果。

## 驗證建議

1. 啟動 mini-shop。
2. 畫面上「一眼看懂進度」先出現 `服務尚未就緒`。
3. 服務 ready 後應變成 `服務已就緒`。
4. 選客戶後，狀態同步顯示「已選擇客戶」。
5. 加購物車後，狀態同步顯示「購物車已加入商品」。
6. 成功 checkout 後，最後一格顯示「已完成一筆成功訂單」。
