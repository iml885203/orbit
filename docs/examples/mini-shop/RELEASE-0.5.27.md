# Orbit mini-shop Release 0.5.27

## 本次目標

讓新手在「命令列 demo」與「UI 一鍵導覽」之間不會因腳本格式造成歧義，減少 mental model 成本。

## 主要變更

- 修正 `docs/examples/mini-shop/apps/web/index.html` 中「命令列示範腳本」的內容產生方式：
  - 從陣列組字串改為純粹可執行的 template literal，讓複製到 terminal 後不再殘留轉義字元（例如 `\"`、`\\`）。
  - 對應腳本：
    - 情境 A（成功下單）
    - 情境 B（付款失敗）
    - 情境 C（庫存不足）
- 保持三情境與 README 說明一致，避免 UI 與文件解釋落差，方便使用者在第一輪就能重現結果。

## 打磨驗證重點（1.0 前）

- 在「命令列示範腳本」複製貼上後，三組情境可直接執行，不需先手修正命令。
- 失敗情境（B / C）仍能保留與 UI 一致的錯誤訊息，便於新手用「錯誤 → 指引 → 修正」的路徑前進。
- 保持既有「第一次 demo（30 秒）」路線不變，僅降低腳本體驗雜訊。

## 下一步

下一版持續打磨方向：再新增 1~2 個「錯誤修復即刻可執行」的情境指引，讓初次用戶在失敗後不只知道「該去哪裡看」，也能直接看到「下一步要下哪個命令」。
