# Film review

The film uses one persistent five-resource graph as its visual subject. It
assembles from scattered cards, shows readiness in dependency order,
de-emphasizes the healthy branch during a configuration failure, and moves
into measured positions in the real dashboard. The same five resources
converge into the Orbit mark. Masked word entrances and synchronized original
music provide the pacing; small state changes remain legible.

Orbit's demonstrated advantages are shared control of host processes and
containers, dependency-aware readiness, actionable diagnostics for coding
agents, and a dashboard exposing the same state. The recovery scene assigns
the configuration change to the coding agent. This is an illustrated workflow,
not a benchmark or a recording of an autonomous repair. It does not claim that
healthy resources alone prove a working application flow.

Evidence:

- `npm run check`: TypeScript passes.
- Initial full-film review: 1,800 frames rendered into H.264, 1920×1080, 60 fps.
- `npm run capture`: actual Svelte dashboard built into an isolated output
  directory, rendered with five synthetic resources, no page errors or missing
  API fixtures. PNG is 2×; measured positions are bundled in
  `public/dashboard-layout.json`.
- `out/full-review.jpg`: reviewed all narrative phases. Commands now sit
  below the graph; the diagnosis panel does not obscure the fault path;
  the complete dashboard fits in the frame; closing copy is fully visible.
- `out/match-review.jpg`: quarter-second samples of the graph-to-dashboard
  handoff, confirming persistent node identity and matched positions.
- `scripts/review-playback.mjs`: normal-speed browser playback through the end,
  with ten screenshots and a machine-readable result in
  `out/playback-review.json`. Playback runs muted for automation.
- FFmpeg full-file decode reports no errors. Source soundtrack mean level is
  −26.8 dBFS and peak is −10.7 dBFS, with no clipping and a closing fade.
- `out/poster.png`: final lockup inspected at 29 seconds.

The conversation revision extends the film to 2,010 frames / 33.5 seconds.
`out/chat-check.png` verifies the user bubble, agent reply, inspect summary,
and subsequent up command at 5.83 seconds. Earlier review images above refer
to the preceding edit; scene timing is now documented in README.md.

The output is a standalone film, published by the website build at
`/media/orbit-launch.mp4` and linked from static covers in both READMEs.
The homepage embeds this film in place of the former inline animation.
Audience reaction remains a creative judgment; this review
verifies the implemented choreography, product claims and artifact integrity.
